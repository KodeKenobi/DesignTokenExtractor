Privacy Policy

Last updated: 2026-06-24

Design Token Extractor processes page styles locally in your browser to provide token extraction, smart capture, and live editor functionality.

Data Collection

  • We do not sell personal data.
  • We do not collect or transmit personal browsing content to external servers for analytics.
  • Any extracted style data is processed locally in the extension UI.

Storage Usage Justification

The extension uses chrome.storage.local to store user preferences and UI state, including selected interface mode, floating panel position/size, and editor state flags. This data remains on the user device and is used only to provide extension functionality.

Permissions

  • activeTab, scripting, and tabs are used to inject tools and extract tokens from the active page.
  • storage is used to persist extension settings.
  • sidePanel is used to support side panel mode.
